# 数据目录

`data/` 保存研究证据和生成产物，不保存业务逻辑。原始材料、规范记录、特征、评价结果和展示报告应分层，避免覆盖或循环引用。

| 子目录 | 用途 | 默认版本控制策略 |
|---|---|---|
| `inbox/` | 人工可见文本或待处理 capture | 仅提交 `*.sample.*` |
| `raw/` | 原始抓取材料和正文 | 不提交 |
| `cache/` | 按内容哈希缓存的下载与解析结果 | 不提交，可重建 |
| `actions/` | 日常行动摘要 | 仅提交脱敏样例 |
| `signals/` | 结构化研究信号 | 仅提交脱敏样例 |
| `industry/` | 行业雷达时点输入 | 仅提交脱敏样例 |
| `portfolio/` | 用户本地持仓快照 | 不提交，不自动归属策略 |
| `research_reports/` | 研报审计 SQLite 数据库 | 不提交 |
| `reports/` | 模块化 Markdown/CSV/JSON 结果 | 视敏感性；默认只保留样例 |
| `broker/` | 券商只读 Shadow 快照 | 不提交 |
| `trading/` | Paper 账本和验证报告 | 不提交 |
| `tmp/` | 测试与临时运行输出 | 不提交，可删除 |

## 文件约定

- 可提交样例使用 `name.sample.ext`，并移除真实姓名、账号、Cookie、Token、持仓和订单标识。
- 时间使用带时区的 ISO 8601；市场日定义同时记录交易日历版本。
- 金额和价格在交易领域使用十进制定点语义，避免二进制浮点误差。
- 原始证据尽量只追加；修正通过新版本和父记录标识表达，不覆盖历史。
- 生成物至少记录生产器版本、配置哈希、输入哈希、运行时点和研究截止日。

新增 `.gitignore` 只会阻止新的未跟踪文件。仓库中已经被跟踪的个人数据不会自动消失，清理前必须单独核验。
