# DeepVan经验规则

## 信号分层

| 类型 | 处理方式 |
|---|---|
| 明确调仓 | 高优先级，但仍需过组合约束 |
| 风险提示 | 优先进入对抗式审查 |
| 研究线索 | 放入观察池，不直接动作 |
| 情绪表达 | 降低置信度 |
| 复盘道歉 | 更新规则库，不直接反向交易 |

## 当前已知倾向

- 偏 AI 半导体基础设施、设备、材料、先进封装。
- 重视资本开支、财报指引和产业链确认。
- 强调仓位分散、不上杠杆、避免肥尾风险。
- 对 A股个股更强调单票上限和止损条件。

## 解释原则

先判断这句话是什么类型，再判断它对组合有什么影响。
