# 采集安全边界

## 原则

- 只读取本人账号已经可见的内容。
- 不绕过登录、验证码、权限、付费墙或平台限制。
- 不批量保存或传播付费原文。
- 保存个人投研需要的时间、标题、链接、关键词、非逐字摘要、结构化信号、动作理由和复盘结果。
- 遇到账号安全、支付、验证码、权限弹窗时停止自动化。

## 采集优先级

1. 接口探测：可用则优先，但当前 DeepVan 星球权限不稳定，不能作为唯一方案。
2. 浏览器可见页：主方案，要求用户在电脑端保持登录和页面可见。
3. Computer Use：兜底方案，用于微信桌面版或手机投屏窗口。
4. 手工粘贴 / 截图：失败兜底。

## 投研边界

- 采集结果只作为信号输入。
- 量化动作建议不自动下单。
- A股个股动作必须证明优于继续持有量化基金。
- 每条强动作必须有反证条件和退出条件。
