# 外部集成

`integrations/` 存放必须在官方客户端或其他外部受控环境中运行的边界脚本。核心项目不假设这些客户端已安装、已登录或已授权。

## 当前集成

- [华泰 MQuant 只读影子快照](htsc_mquant/README.md)：在官方客户端内部读取资金、持仓、委托和成交，规范化为本地 JSON。脚本没有下单或撤单方法。

## 适配器原则

- 先核验当前官方 SDK 契约，再写适配器；旧手册只能作为线索。
- 登录、密码、验证码和账户选择由用户在官方客户端完成，不传给本项目。
- 外部对象必须转成版本化 Schema，并记录完整性、时效和来源限制。
- 读取成功不等于来源已认证，内容哈希也不等于官方签名。
- 任一分页、字段、账户绑定或一致性检查失败时，下游必须明确拒绝。
